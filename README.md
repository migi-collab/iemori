# おうちのしおり（体験版）

宅飲みの家主が、家の案内を友達に共有するアプリ案の体験版です。

https://migi-collab.github.io/ouchi-shiori/

- 家主が一度だけ家の情報（場所・近くのお店・家にあるもの・お願い・ゴミの日）を登録します。
- 友達はURLを開くだけで、案内・買い出しリスト・ゴミの分け方・割り勘を見られます。
- 見本の家が最初から入っています。入力した内容は、開いた人のブラウザの中だけに保存されます。
- 現在地からのお店探し、住所からのゴミの日取得、PayPay送金は見本の動きです。

`index.html` 1ファイルだけで動きます。
